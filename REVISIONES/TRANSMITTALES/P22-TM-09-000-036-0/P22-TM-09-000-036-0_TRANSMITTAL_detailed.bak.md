## 1. Executive Summary

**TRANSMITTAL VERDICT: 2 — Approved as noted.** This transmittal responds to BW Water submittals **25007-0082, 25007-0083, 25007-0084 and 25007-0085**, received between 21 and 26 August with nine documents between them. This transmittal disposes eight of them; the Project Schedule Rev B is followed through the weekly project coordination and carries no response code here. Tally: 3 Code 1, 5 Code 2. No document returns to revision.

**Disposition at a glance:**

- **UHPRO Structural Design Criteria Rev 0 — Code 1.** No action on this document.
- **Piping Layout Rev D — Code 2.** State the datum of the tie-in elevations, add the CIP connections to the schedule, and identify the two panel enclosures, at Rev 0.
- **3D Model Rev B — Code 2.** Carry the document code and revision index in the file properties, and resolve the reuse of line number 09-001, at Rev 0.
- **GA of SWRO System Skid Rev 0 — Code 1.** The drawing is not held; correct the two note references, one of which cites a document code that does not exist.
- **GA of Antiscalant Dosing Tank Rev C — Code 2.** Reconcile the anchor hole dimension against the M12 bolt and state the level mark elevation, at Rev 0.
- **Datasheet of RO HP Feed Pump Rev E — Code 1.** Issue at Rev 0 for construction before the Factory Acceptance Test opens.
- **Datasheet of Feed Turbocharger Rev E — Code 2.** Delete STYLE 77 from the four connection callouts and issue at Rev 0 before the Factory Acceptance Test opens.
- **Datasheet of Interstage Turbocharger Rev E — Code 2.** Delete STYLE 77 from the four connection callouts and issue at Rev 0 before the Factory Acceptance Test opens.

**Why the verdict is 2 and no document returns to revision.** Every document of these four submittals answers comments ADASA raised at an earlier transmittal, and none of them is wrong in its own content. What remains open are conditions that fall due when each document is issued at Rev 0, and two reference corrections on a drawing already issued for construction, which ADASA does not hold for that reason.

**On the GA of SWRO System Skid Rev 0, ADASA is blunt.** It is the only document of these submittals issued for construction, so the conditions of its previous Code 2 fell due at this issue. That Code 2 was one action, correct three document references in the notes block, and **only one of the three was corrected**:

- **Note 8 is unchanged on both sheets.** It cites P22-ET-09-006-01, which is not a valid document code in the project numbering, and it is the note that refers the fabricator to the nominal wall thickness per pipeline. The correct code is **P22-ET-09-006-001**, and ADASA states it here so that it stands on the record whether or not the drawing is ever re-issued.
- **The reply given to note 8 is refuted by the annex BW Water attached to support it.** The comment sheet answers that a snapshot shows the number was already submitted earlier in the project. That snapshot, the last page of the submitted file, writes the code with three sequential digits, and the row below it follows the same form.
- **Note 6 was corrected on Sheet 2 and not on Sheet 1**, so the same drawing now refers the same instrument function matrix to two different revisions of the same list.

ADASA records that this drawing was issued for construction carrying a reference to a document code that does not exist. The drawing is not held, because the documents referred to remain identifiable and neither error changes its content. That is the reason for the code, not an acceptance of the point.

**The remaining open conditions are reiterated, not escalated.** The Piping Layout and the 3D Model were submitted for approval, and the conditions ADASA set on them at Transmittal N30 fall due when each document is issued at Rev 0. They are stated again here, with the record that this is the second cycle in which they remain open, and each is itemised on its annotated PDF.

**The three Fedco datasheets have to close.** This submittal brings the datasheets of the RO high pressure feed pump and of the two turbochargers at Rev E, submitted for approval. These three items are purchased and built: they were approved as noted at Rev D in Transmittal N11, each with a single minor note, and the equipment was procured and manufactured on that basis. They are now due at the workshop, and the high pressure pump is programmed for installation inside the container within days.

Equipment that is bought, built and about to be installed cannot keep exchanging approval revisions of its own datasheet. **ADASA asks that the three be issued at Rev 0 for construction before the Factory Acceptance Test opens on 7 September 2026**, so that the documentary record matches the physical state of the equipment. ADASA will not continue receiving and returning approval revisions of datasheets for equipment already on its way to assembly.

**Comment sheet coverage.** Four of the eight documents disposed here arrive with no consolidated comment sheet, among them the UHPRO Structural Design Criteria, which carried one at Rev B with nine entries and lost it at Rev 0. Where a sheet is present it does not always transcribe what was asked: the Piping Layout sheet records one of the three conditions issued at Transmittal N30, and the 3D Model sheet omits the file identification requirement altogether. A reviewer working from those sheets cannot see what was asked.

**Return date.** Clause 37.2 of the Special Administrative Conditions (BAE 12803) gives seven working days: Tuesday 1 September for 25007-0082 and 25007-0083, Wednesday 2 September for 25007-0084 and Friday 4 September for 25007-0085. This transmittal is issued within all four. ADASA notes that the four submittals requested return three calendar days after issue, and that the date requested for 25007-0085 falls on a Saturday.
